Superstore Sales Analysis – Power BI Project
📊 Project Overview

This project analyzes sales performance using the Superstore dataset.
It includes visual insights such as revenue, profit margin, top products, and sales distribution across categories and regions.

The report contains two pages:

Dashboard Page – KPIs, charts, slicers

Product Insights Page – Detailed product-level analysis

✅ Features
1. KPIs

Total Sales

Total Profit

Average Profit Margin

Total Orders

2. Slicers

Order Date slicer

Category slicer

3. Visualizations

Bar Chart –  Products by Sales

Line Chart – Sales Over Time

Donut Chart – Sales by Category

Map Chart – Sales by State

Product Table – Product-level sales and profit

🛠️ Tools Used

Power BI Desktop

Power Query (Data cleaning & transformations)

DAX (Calculated columns & measures)

📁 Dataset

Dataset used: Superstore Orders Dataset (CSV)

Key columns:

Order Date

Sales

Profit

Category

Sub-category

Product Name

Customer

Region....

📐 Data Transformations (Power Query)

Removed duplicate rows

Cleaned missing values

Formatted date column

Added calculated column:

Profit Margin = Profit / Sales

📈 Key Insights

Technology category has the highest sales

Profit margin varies significantly by product

A small group of products generate majority of revenue

Seasonal sales patterns visible across months

📦 How to Use

Download the .pbix file from this repository

Open using Power BI Desktop

Use slicers to filter dashboard views

Explore page navigation buttons for deeper insights
